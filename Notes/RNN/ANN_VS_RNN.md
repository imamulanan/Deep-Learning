## ANN এবং RNN — মূল পার্থক্য

নিচে `ANN` (Artificial Neural Network) ও `RNN` (Recurrent Neural Network)-এর সংক্ষিপ্ত ও পরিষ্কার তুলনা দেওয়া হলো।

### 1️⃣ সংক্ষিপ্ত ভূমিকা

- **ANN (Artificial Neural Network)** — সাধারণ ফিডফরওয়ার্ড নেটওয়ার্ক; প্রতিটি ইনপুট সাধারণত স্বাধীন। স্ট্যাটিক ডেটা (যেমন ইমেজ, ট্যাবুলার)–এ ভাল কাজ করে।

- **RNN (Recurrent Neural Network)** — রিকারেন্ট কনফিগারেশন; প্রতিটি টাইমস্টেপে পূর্ববর্তী হিডেন স্টেট ব্যবহার করে কনটেক্সট ধরে রাখে। সিকোয়েন্স ডেটা (টেক্সট, অডিও, টাইম সিরিজ)–এর জন্য উপযোগী।

### 2️⃣ স্ট্রাকচার উদাহরণ

ANN: Input → Hidden Layer → Output

RNN (টাইমস্টেপগুলোর সিরিজ):

x1 → [h1] → y1  
x2 → [h2] → y2  
x3 → [h3] → y3

এখানে সাধারণভাবে h2 = f(x2, h1), h3 = f(x3, h2) ইত্যাদি।

### 3️⃣ তুলনামূলক টেবিল

| Feature | ANN | RNN |
| ------- | --- | --- |
| Input টাইপ | Independent (স্ট্যাটিক) | Sequential / Time-dependent |
| Memory | নেই (no state across examples) | আছে (hidden state → পূর্ববর্তী ইনফো দেয়) |
| Use cases | ইমেজ ক্লাসিফিকেশন, ট্যাবুলার ডেটা | NLP, স্পিচ, টাইম-সিরিজ প্রেডিকশন |
| Architecture | Feedforward (loop-free) | Recurrent (hidden layer-এ লুপ/রিকারেন্স) |
| Sequence handling | নেই | আছে — পূর্ববর্তী স্টেপ মনে রাখে |

### 4️⃣ সুবিধা ও সীমাবদ্ধতা (সারসংক্ষেপ)

- **ANN:** সহজ ট্রেনিং, স্থিতিশীল গ্র্যাডিয়েন্ট; সিকোয়েন্স কনটেক্সট ধরতে অক্ষম।
- **RNN:** সিকোয়েন্স কনটেক্সট ধরতে পারে; তবে দীর্ঘ সিকোয়েন্সে vanishing/exploding gradient সমস্যা থাকতে পারে — এ কারণেই LSTM/GRU ব্যবহৃত হয়।

### 5️⃣ দ্রুত স্মরণীয় সূত্র

- `ANN` = “পাস্ট মেমোরি নেই” — কেবল present input-এ কাজ করে।
- `RNN` = “পাস্ট মনে রাখে” — previous input/context ব্যবহার করে পরবর্তী প্রেডিকশন করে।
